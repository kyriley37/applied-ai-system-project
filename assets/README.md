# Mermaid Diagram Files

All 8 architecture diagrams are included as individual `.mmd` files:

## Files Included

1. **1_system_architecture.mmd** - High-level system architecture overview
2. **2_agentic_workflow.mmd** - 6-step agentic reasoning sequence
3. **3_component_interaction.mmd** - Component interaction and dependencies
4. **4_data_flow.mmd** - Data flow from input to output with logging
5. **5_rag_system.mmd** - RAG knowledge base retrieval mechanism
6. **6_testing_framework.mmd** - Testing and validation suite
7. **7_confidence_calibration.mmd** - Confidence score computation logic
8. **8_class_diagram.mmd** - Class relationships and methods

## How to Generate PNG Images

1. Open https://mermaid.live in your browser
2. For each diagram:
   - Copy the contents of the `.mmd` file
   - Paste into Mermaid Live Editor
   - Click the download button (↓) 
   - Save with a descriptive name
3. Store all PNG files in this `assets/` folder

## Recommended Naming

When exporting, use these names:
